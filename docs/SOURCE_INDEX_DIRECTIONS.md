# Source non-primary index directions

The native table importer now retains each non-primary index field's explicit
ASC/DESC direction. Both accepted MDBTools CREATE INDEX and MySQL ALTER TABLE
ADD INDEX declarations use an ordered, complete identifier/direction parser.
Previously the parser extracted only quoted identifiers and silently discarded
DESC. Unknown suffixes, expressions, missing commas and trailing commas now
reject the schema rather than silently converting it to a different index.
Escaped backticks, composite key order and uniqueness remain preserved.

AccessIndex carries a direction vector; a legacy empty vector means all ASC.
Any nonempty vector must exactly match its column list. Native CREATE INDEX
uses each checked direction within the same existing import transaction, so a
bad declaration cannot leave partially imported data/indexes/log records.
This fixes structural metadata; it does not prove complete Jet sorting/locale,
NULL uniqueness, filtering, clustered indexes or original-format writing.

The optional zero-row technical Jet4 reference is generated by
`tests/jet_binary_reference/JetIndexReference.java` using the same independently
verified Jackcess5.0.4 tool described in JET_BINARY_IMPORT.md. It writes two real
named indexes: one UNIQUE(first_key DESC,second_key ASC), one(first_key ASC).
A separate read-only reopen checks their actual Jet properties. This is no
mockup, business dataset or app Java dependency. The generator refuses replacing
an existing file. Enable the existing table_import_contracts target with
LINACCESS_JET_INDEX_REFERENCE pointing at index-order-probe.mdb. That regression
checks source schema, actual full MDB import, PRAGMA main.index_xinfo directions,
ordered fields, uniqueness, zero rows and the unchanged source SHA-256.

This does not introduce a DAO.Indexes catalog. MDBTools1.0.0 deliberately exports
generated primary-index names (MySQL _pkey, other backends table_pkey) and also
omits primary-index directions; those cannot establish original DAO identities.
Public implementation reference: mdbtools/v1.0.0 src/libmdb/backend.c,
mdb_get_index_name and mdb_print_indexes. Native SQLite index names also include
backend/import prefixes. No generated name is claimed as a real Access name.
